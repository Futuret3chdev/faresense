# Driver Desk

Two on-device tools for Uber drivers.

- **FareSense** — should you tap Accept?
- **ShiftClose** — should you stay online?

Produced by Futuret3ch and MemeTorrent.

Open `index.html`, `offer.html`, or `shiftclose.html`. Vehicle settings persist in localStorage and are shared between tools.

Not affiliated with Uber. Decision aid only.

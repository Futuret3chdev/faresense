# Driver Desk

Three on-device tools for Uber drivers.

- **FareSense** — should you tap Accept?
- **ShiftClose** — should you stay online?
- **Fence** — which Melbourne suburbs will you work?

Produced by Futuret3ch and MemeTorrent.

Open `index.html`, `offer.html`, `shiftclose.html`, or `fence.html`. Vehicle settings persist in localStorage and are shared between tools.

Not affiliated with Uber. Decision aid only.
